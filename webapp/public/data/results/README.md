# Vorberechnete Tagesergebnisse

Hier liegen die stündlichen Modell-Ausgaben pro Station für die Datums-Analyse.

Dateinamen-Schema: `{station_id}_daily.json`

Aktuelle Dateien sind Platzhalter, erzeugt von `webapp/scripts/generate_placeholders.mjs`.
Sobald die echten Vorhersagen vorliegen, überschreibt das Python-Export-Snippet aus
`webapp/README.md` diese Dateien.
